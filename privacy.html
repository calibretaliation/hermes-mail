Hermes Mail — Privacy Policy

Last updated: October 26, 2026

Hermes Mail is a private tool built and used by a single person (the "owner") for their own Gmail accounts. It is not offered to the public.

What data is accessed

With the owner's consent, Hermes Mail uses the Gmail API with the read-only scope (https://www.googleapis.com/auth/gmail.readonly) to read newly received, unread messages in the owner's inbox: sender, recipients, subject, date, labels, attachment names and message text. It never sends, modifies, labels or deletes email.

How the data is used

Message content is used only to decide which messages are important and to write a short summary for the owner. To produce the summary, message text is sent to a third-party AI model provider (through OpenRouter) and the summary is posted to the owner's private Discord server. Data is not used for advertising, is not sold, and is not shared with anyone else.

Storage

OAuth tokens and a list of already-processed message IDs are stored locally on the owner's own computer. Message content is not stored by Hermes Mail beyond what is needed to create the summary.

Limited Use

Hermes Mail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
